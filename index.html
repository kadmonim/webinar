Setting Up Claude Code on Windows (WSL)

1

Install WSL (Windows Subsystem for Linux)

Open PowerShell as Administrator and run: wsl --install. Restart your computer when prompted. This gives you a Linux environment inside Windows.

2

Open your command prompt

Search for Ubuntu in the Start menu and open it. The first time, you'll be asked to create a username and password — just pick something simple.

3

Install Claude Code

In the Ubuntu terminal, first run cd ~ to make sure you're in your home folder, then run: curl -fsSL https://claude.ai/install.sh | bash

This installs Claude Code and everything it needs automatically.

4

Log in to Claude Code

Run: claude

This launches Claude Code and walks you through logging in with your existing Claude account. Follow the prompts — that's it, you're ready to go!

Frequently Asked Questions

Do I need to know how to code to use Claude Code?
Not at all! Claude Code is designed to let you describe what you want in plain English. You tell it what to build or fix, and it handles the code. That said, having a basic understanding of what you're trying to build will help you give better instructions.
Is Claude Code free?
Claude Code itself is free to install. To use it, you need a Claude account. We recommend the Max plan at $40/month — it's designed for power users and gives you the best experience. Non-profits can access this plan at a discounted rate.
What is WSL and why do I need it?
WSL (Windows Subsystem for Linux) is a feature built into Windows that lets you run a Linux-style terminal. Claude Code works best in a Linux or Mac terminal environment, so on Windows, WSL is the recommended way to run it. Think of it as a small "Linux mode" living inside your Windows PC.
What is Neon and how does it fit in?
Neon is a cloud-hosted Postgres database. When you build projects with Claude Code that need to store data (like a list of users, form responses, etc.), Neon is a great place to put that data. It has a free tier and works seamlessly with the kinds of projects Claude Code helps you build.
What can I actually build with Claude Code?
All kinds of things — websites, internal tools, scripts that automate repetitive tasks, simple apps with databases, API integrations, and more. If you can describe it clearly, Claude Code can usually help you build it.
Is my code and data private?
Your code runs entirely on your own machine. When you send a message to Claude Code, that message (including any code you share) is sent to Anthropic's API. Anthropic's privacy policy applies. Avoid pasting sensitive credentials or personal data directly into the chat.
Where can I get help if I'm stuck?
The best places to start are the official Claude Code docs and the GitHub repository, where you can open issues or browse what others have asked. You can also just ask Claude Code itself — type /help at any time.
